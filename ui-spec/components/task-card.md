# Component: TaskCard

## Doel
Samenvattende weergave van een taak in de lijst.

## Toont

- taaknaam
- huidige workflow stap
- progress indicator (visueel)
- aantal objecten
- aantal fouten
- tijd in huidige stap
- status label

## Status labels

- "Actie vereist"
- "In uitvoering"
- "Wacht op accordering"
- "Gepland"
- "Afgerond"

## Visuele signalen

- rood → fouten aanwezig
- oranje → actie vereist
- grijs → gepland
- groen → afgerond

## Progress indicator

- gebaseerd op workflow stap
- visueel als progress bar

## Interactie

- klikbaar (opent taak detail)
