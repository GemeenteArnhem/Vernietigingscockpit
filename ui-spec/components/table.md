# Component: DataTable

Gebaseerd op NLDS Data Table

## Features
- sorteren per kolom
- filteren per kolom
- selectie per rij
- bulk selectie

## Props
- data[]
- columns[]
- selectable = true

## Gedrag
- hover state verplicht
- geselecteerde rij visueel gemarkeerd

## Bulk gedrag

- header checkbox selecteert alle zichtbare rijen
- selectie blijft behouden bij filtering

## Validatie weergave

- foutstatus per rij zichtbaar (bijv. rood icoon)
- tooltip met foutmelding mogelijk
