# Begrippenlijst Cockpit-dekkingInTijdtypen

| Kenmerk | Waarde |
|---|---|
| Naam | Cockpit-dekkingInTijdtypen |
| Identificatie | `urn:vernietigingscockpit:begrippenlijst:cockpit-dekkingintijdtypen:1.0` |
| Versie | 1.0 |
| Type | Open |
| Basis | ADR-0005; MDTO `dekkingInTijdType` (MDTO heeft hiervoor geen begrippenlijst) |

Het soort periode in `dekkingInTijd`. MDTO: *dekkingInTijd heeft betrekking op de inhoud van het informatieobject, niet op het informatieobject zelf*. Gebeurtenissen op het object zelf zijn events.

| Code | Label | Definitie |
|---|---|---|
| `looptijd` | Looptijd | De periode waarin de zaak, het dossier of de serie liep: van start tot afhandeling of afsluiting. |
| `inhoudelijke_periode` | Inhoudelijke periode | De periode waar de inhoud betrekking op heeft, zoals een belastingjaar, een subsidieperiode of de geldigheid van een vergunning. |
| `registratieperiode` | Registratieperiode | De periode waarin gegevens in het object zijn geregistreerd, bijvoorbeeld bij een register of een administratie. |
